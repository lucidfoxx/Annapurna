# SharePlate Backend

A runnable FastAPI starter backend for SharePlate. It includes authentication, role-based access, food listings, donation requests, volunteer handovers, notifications, matching, and an impact summary.

## Requirements

- Python 3.11+
- `uv`
- MySQL 8+ (or a compatible MySQL server)

## Setup

From this directory:

```bash
cp .env.example .env
```

Edit `.env` and set your MySQL connection string and a long random `SECRET_KEY`.

Create the MySQL database and user yourself, then grant that user access to the SharePlate database. The application deliberately does not create or drop databases automatically.

Install dependencies and create the lock file:

```bash
uv sync
```

Create tables for local development:

```bash
uv run python -m app.db.create_tables
```

Run the API:

```bash
uv run uvicorn app.main:app --reload
```

Open Swagger UI at http://127.0.0.1:8000/docs.

Run tests:

```bash
uv run pytest
```

## Alembic migrations

Alembic is configured. After changing models, create a migration:

```bash
uv run alembic revision --autogenerate -m "describe change"
uv run alembic upgrade head
```

Review autogenerated migrations before applying them. Never run destructive migrations against data you need.

## Main endpoints

- `GET /api/health`
- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/auth/me`
- `POST /api/listings`
- `GET /api/listings`
- `GET /api/listings/{listing_id}`
- `PATCH /api/listings/{listing_id}`
- `DELETE /api/listings/{listing_id}`
- `POST /api/requests`
- `GET /api/requests/my`
- `PATCH /api/requests/{request_id}/accept`
- `PATCH /api/requests/{request_id}/reject`
- `GET /api/handovers/available`
- `POST /api/handovers/{handover_id}/assign`
- `PATCH /api/handovers/{handover_id}/pickup`
- `PATCH /api/handovers/{handover_id}/delivery`
- `GET /api/notifications`
- `PATCH /api/notifications/{notification_id}/read`
- `GET /api/matching/recommendations`
- `GET /api/dashboard/impact`

## Important implementation notes

- Registration accepts a role, which is convenient for a hackathon demo. Before a public deployment, restrict privileged role assignment and add organization verification/admin workflows.
- This starter does not include email/SMS delivery, file uploads, QR verification, maps, or production deployment configuration.
- The food-safety fields are informational only. SharePlate does not certify that food is safe.
- The first local table creation uses SQLAlchemy metadata for convenience. Use Alembic migrations for ongoing schema changes.
